# Java Collections, Lambda Expressions & Interfaces

This repository contains a collection of hands-on Java exercises focused on deepening the understanding of core Java development, Object-Oriented Programming (OOP) paradigms, and modern functional programming features introduced in Java 8+.

---

## 📌 Topics Covered

### 1. Java Collections Framework
- **Lists, Sets, and Maps**: Exploring common collection interfaces and their underlying data structures.
- **Iteration and Manipulation**: Traversing, filtering, and sorting collections efficiently using standard APIs.

### 2. Interfaces & Abstraction
- **Abstract Contracts**: Defining polymorphic behavior and standard contracts using interfaces.
- **Hierarchical Design**: Structuring domain models using abstract classes, standard interfaces, and deep inheritance trees (e.g., 2D shapes, geometric points, and coordinate calculations).

### 3. Functional Interfaces & Lambda Expressions
- **Lambdas**: Writing concise, functional-style code to replace verbose anonymous inner classes.
- **Built-in Functional Interfaces**: Utilizing standard interfaces from `java.util.function` (such as `Predicate`, `Function`, `Consumer`, and custom single abstract method interfaces).

### 4. Object-Oriented Programming (OOP) Fundamentals
- **Encapsulation & Immutability**: Designing robust models with strict access control and immutability where applicable.
- **Polymorphism & Dynamic Binding**: Leveraging runtime dispatch and interface implementations to decouple business logic from specific classes.

---

## 🛠️ Tech Stack & Requirements

- **Language:** Java 8+ (Java 17/21 recommended)
- **Tooling:** Compatible with standard IDEs (Eclipse, IntelliJ IDEA, VS Code)
- **Build/Execution:** Plain Java / IDE runtime
